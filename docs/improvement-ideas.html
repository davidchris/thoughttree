Three ideas to make the tree think harder.

ThoughtTree already nails the hard part — conversations as a DAG, branch and converge, multi-provider via ACP. These three proposals close the gap between the promise in the README and what the UI can do today. None of them overlap with the current backlog/.

01

idea 01 — the missing core feature

Branch Compare & Synthesis

The README's own pitch is "compare responses across branches" — but today the only way to compare two branches is to squint at two collapsed nodes on the canvas. And while the graph model already supports multi-parent nodes, nothing in the UI celebrates or drives the merge — the single most differentiating concept ThoughtTree has over every linear chat app.

Proposal: select two (or more) sibling agent nodes → a split Compare view renders them side by side with agreement dimmed and unique claims highlighted per branch. One button — Synthesize — creates a multi-parent merge node pre-loaded with a synthesis prompt, turning the DAG's convergence superpower into a one-click workflow.

Today

Pan between nodes, open side panel twice, hold both answers in your head. Merge nodes exist in GraphModel but users must wire them by hand.

Proposed

Shift-click two agent nodes → ⌘⇧C opens Compare. Unique claims highlighted. "Synthesize" spawns the merge node and generates in one step.

02

idea 02 — navigation at scale

Command Palette & Graph Search

A research graph earns its keep at 40+ nodes — exactly the point where panning and squinting stops working. Today there is no way to search node content: search_files only matches filenames for @-mentions, and the minimap shows shapes, not meaning.

Proposal: ⌘K opens a palette that fuzzy-searches every node's content and AI summary (all already in memory in nodeData — no backend needed). Selecting a result animates the viewport to the node via ReactFlow's setCenter and flashes it. The same surface doubles as a command runner — tidy graph, export thread, switch model — which also fixes the advertised-but-unbound ⌘L shortcut for free.

Today

"Where did Claude explain the borrow checker thing?" → pan, zoom, expand nodes one by one. Summaries help only if visible on screen.

Proposed

⌘K → type three words → jump. Every node reachable in under two seconds, every toolbar action reachable without the mouse.

03

idea 03 — trust & control

Context Lens & Stop Control

In a DAG, "what is the model actually seeing?" is a harder question than in a linear chat — context is the path from root to node, and users currently have zero visibility into how big that path has grown or what a deep branch costs. Worse: once generation starts, there is no stop button — a wrong prompt on a deep branch runs to completion while its whole lineage is locked from editing.

Proposal: a Context Lens in the side panel — a meter showing estimated path tokens vs. context window, a per-node breakdown, and an estimated cost line — plus a Stop button wired to ACP's session/cancel. The lens turns branch pruning from guesswork into an informed act; the stop button returns control mid-stream.

Today

Token counts invisible everywhere. Mis-sent prompt = watch it stream, lineage locked until done. stop_reason is received and discarded.

Proposed

Path meter + per-node tokens + est. cost in the panel; ■ Stop (⌘.) aborts the stream, keeps partial text, unlocks lineage.
