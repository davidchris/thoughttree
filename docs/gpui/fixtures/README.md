# Shared desktop demonstration

`parity.thoughttree` is an authored version 5 project. It contains no personal data or live provider output.
Both desktop frontends can open this file.

The graph has 11 nodes and 10 edges. It includes two branches, a merge, an embedded image, a Vault file, and historical provider attribution.
The synthesis answer includes a table, Rust code, inline math, display math, Mermaid, task lists, and provenance.
Its unmatched citation and partial evidence are intentional.

For isolated desktop checks:

1. Copy this directory to a temporary directory.
2. Use that temporary directory as the demonstration Vault.
3. Open the copied `parity.thoughttree` file.
4. If the file card reports a change, select Reload file to adopt its current modification time.
5. Open the `parity-synthesis` node to inspect rich content.

The file node uses `vault/reading-notes.md`, relative to the demonstration Vault.
The image node embeds the bytes from `vault/synthetic-chart.png`.
All text nodes contain fresh summaries, so opening the fixture does not require automatic summary generation.

Useful node IDs:

| Node | Purpose |
| --- | --- |
| `parity-synthesis` | Rich answer, citations, and provenance |
| `parity-merge` | Two-parent conversation context |
| `parity-file` | File metadata, preview, and Reload |
| `parity-image` | Image attachment and user editing |
| `parity-history` | Incomplete imported answer from a retired provider |

The fixture supports repeatable demonstrations. It does not simulate successful provider calls or prove feature parity.
