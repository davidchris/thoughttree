# Desktop frontend parity

This checklist records the Tauri frontend at `c87a351`. It covers desktop behavior from the source code and existing tests.
Every acceptance box starts unchecked. A source audit does not verify the GPUI implementation.

Each completed row needs a reproducible test, a recorded manual result, or both.
Screenshots prove visible states. They do not prove persistence, concurrency, permission routing, or file safety.
Native controls can differ in appearance. They must preserve the behavior described here.
